# Unionize

Сайт-супутник настільної гри **Unionize** — навчальної гри про профспілкову
діяльність. Замовник — ПРМТУ (Професійна спілка робітників морського
транспорту України). Аудиторія: курсанти морських навчальних закладів,
портовики, моряки.

Сайт **доповнює** фізичну гру, а не керує нею: він не веде партію, не
синхронізує гравців і не замінює жоден компонент коробки.

## Що на сайті

| Розділ | Що робить |
|---|---|
| Головна | Жива тривимірна сцена столу з полем і кубиками, які можна кидати |
| Правила | 25 питань-відповідей і калькулятор підсумкового рахунку |
| Поле | Інтерактивна карта клітинок із описом кожної |
| Рейтинги | Топ гравців і закладів, дані — з таблиці організатора |
| Архетип | Тест профспілкової поведінки з картинкою для поширення |
| Додаткова можливість | Завдання й вікторина для клітинки «Додаткова можливість» |

## Технології

Astro 5 зі статичною збіркою, звичайний TypeScript без UI-фреймворків,
власні CSS-токени без Tailwind, локальні шрифти `woff2`, three.js — лише
для першого екрана й лише лінивим завантаженням.

## Розробка

```bash
npm install
npm run dev      # локальний сервер
npm run build    # перевірка типів + збірка у dist/
npm run preview  # переглянути зібране
```

## Контент окремо від коду

Увесь текстовий вміст — у `data/*.json`. Додати питання до FAQ, завдання,
клітинку поля чи питання вікторини можна без жодної зміни коду.

У вікторину потрапляють **тільки** записи зі `status: "ready"`.
Координати клітинок поля — у відсотках, а не в пікселях, щоб зміна арту
не вимагала правок у коді.

## Змінні середовища

Див. `.env.example`. Без них сайт працює штатно — лічильник рідкості
архетипів просто показує запасні відсотки з `data/archetypes.json`.

## Публікація

Кожен push у `main` збирає сайт і публікує його на GitHub Pages
(`.github/workflows/deploy.yml`).
